# simplest-bitcoin-book

Web version for [The Simplest Bitcoin Book Ever Written](https://thesimplestbitcoinbook.net/) by Keysa Luna.


## Run website locally
1. Install dependencies
2. Run
    ```
    npm install
    npm run book:dev
    ```
